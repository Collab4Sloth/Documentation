Detailed Description

FunctionCoefficient defined by a tabulated function read from a CSV file.

The coefficient is evaluated at a physical mesh point, mapped to the CSV input coordinates according to the geometry (Cartesian or Axisymmetric). Through Coefficient::compute(), the mesh point must be passed as the first argument (input_vector), as done by MfemFileCoefficient.

Note
Only the value is available: gradient and Hessian abort if evaluated.

double FileCoefficient::value ( double  time,
std::span< const double >  coordinates 
) const

Evaluate the coefficient at a given time and physical mesh point.

Maps the mesh point to the CSV input coordinates according to the geometry, then interpolates the tabulated function:

  • Cartesian: coordinates are used as is;
  • Axisymmetric: r = sqrt((x - xc)^2 + (y - yc)^2), and z = coordinates[2] is appended when the CSV is (t, r, z, F).
