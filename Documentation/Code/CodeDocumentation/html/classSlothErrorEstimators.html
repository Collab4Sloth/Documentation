std::shared_ptr< mfem::ErrorEstimator > SlothErrorEstimators::get_value ( mfem::ParGridFunction &  x,
mfem::ParFiniteElementSpace &  fespace,

)

Return the error estimator of x, ready to compute the local errors of the current solution on the current mesh.

The estimator and its flux spaces are built once per solution field, and reused at each AMR pass:

  • no allocation of collections/spaces at each pass;
  • after a mesh modification, the flux spaces are updated by the mfem estimator itself (ComputeEstimates() calls Update(false), which is valid whatever the number of mesh modifications since the previous estimate);
  • Reset() is called so that the estimates are recomputed even when the mesh is unchanged (the solution has changed). The estimator is rebuilt only if the mesh or the polynomial order associated with x has changed.

The returned estimator is owned by this object: it must not be used after the next call to get_value() for the same x, nor after the destruction of this object.
