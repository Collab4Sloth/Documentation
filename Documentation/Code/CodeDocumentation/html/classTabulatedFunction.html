Detailed Description

Reads a CSV table (t, x1..xN, F) sampled on a structured grid and provides fast (multi)linear interpolation on it. The number of inputs N (1, 2 or 3) is auto-detected from the CSV. No geometry conversion is applied: points are given in CSV coordinates.

Construct a tabulated function from a CSV file.

Reads the samples from csv_path with read_csv(), then reorganizes them into a rectilinear (time × inputs) grid with build_grid(), which sets up the axes, detects uniform spacing and fills data_.

Interpolate the table at a point given in CSV coordinates.

The point is expressed in the coordinates of the CSV input columns (x1..xN) as stored in the file

Performs a separable multilinear interpolation on the rectilinear (time × inputs) grid:

  • the time axis and each input axis are searched independently with locate(), which returns the lower cell index and the normalized local coordinate (weight) within that cell;
  • at each of the two bracketing time slices, the table is interpolated over the inputs by summing the contributions of the 2^N cell corners, each weighted by the product of the per-axis linear weights;
  • the two values are then linearly interpolated in time.

Degenerate axes are handled explicitly: a single-point input axis has no upper neighbour (its upper corners are skipped), and a single time value gives a stationary field (no time interpolation).

Parameters
tTime at which the table is evaluated.
posPoint in CSV input coordinates. Its size must be equal to the number of input columns of the CSV.
Returns
double Interpolated value at (t, pos).
