# Tutorials

This section provides practical tutorials and tips for using specific features of `SLOTH`.

## Available Tutorials

- **Tutorial 1 - SLOTH Input Files in a Nutshell**  
  Learn how a SLOTH input file is structured, from headers to time marching, and how each object fits in. Also available as [slides (PDF)](InputFile/SLOTH_input_files_in_a_nutshell.pdf).  
  → [Open the tutorial](InputFile/index.md)
- **Tutorial 2 - Coefficients with Sympy**  
  Learn how to describe the physics of a problem with `Coefficient` objects and how to generate your own coefficients from a JSON file with Sympy. Also available as [slides (PDF)](Coefficients/SLOTH_coefficients_with_Sympy.pdf).  
  → [Open the tutorial](Coefficients/index.md)
- **Tutorial 3 - Performing a Save/Restart Simulation**  
  Learn how to save the state of a simulation and restart it from a previously saved iteration.  
  → [Open the tutorial](SaveRestart/index.md)
- **Tutorial 4 - Using Adaptive Mesh Refinement**  
  Learn how to enable Adaptive Mesh Refinement.  
  → [Open the tutorial](AMR/index.md)
