Detailed Description

template<class VARS>
class AdvectionBoundaryNLFormIntegrator< VARS >

Upwinded boundary term of the advection operator on boundary bdr_id:

R_r = ( (v.n)^+ u_c + (v.n)^- u_in , psi_r )_Gamma J_rc = ( (v.n)^+ phi_c, psi_r )_Gamma

with (a)^+ = max(a, 0), (a)^- = min(a, 0):

  • outflow (v.n > 0): the interior value u_c leaves the domain,
  • inflow (v.n < 0): the incoming flux (v.n) u_in is imposed.

v is given by the (domain) velocity coefficients of the advected block (see VelocityField: Velocity_X/Y/Z or v = alpha grad(a)), u_in by the Inflow coefficient attached to the boundary. Both can depend on the coordinates, the time and the auxiliary variables, not on the unknowns.

The integrator is added automatically (see OperatorBase::build_rhs_nonlinear_form) on each boundary holding an Inflow coefficient. Default: r = c = block. See AdvectionBoundaryCH for the split Cahn-Hilliard case.
