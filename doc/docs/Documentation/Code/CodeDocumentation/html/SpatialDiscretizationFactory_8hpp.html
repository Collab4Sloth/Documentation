◆ setSpatialDiscretization()

template<class T , int DIM, class... Args>
std::vector<SpatialDiscretization<T, DIM>*> setSpatialDiscretization ( std::size_t  N,
bool  shared_is_periodic,
Args &&...  args 
)

Build N SpatialDiscretization<T, DIM> objects sharing the same mesh, returned directly as a SPAS-compatible std::vector<SpatialDiscretization<T, DIM>*>: the first one is built by forwarding args... verbatim to whichever SpatialDiscretization<T, DIM> constructor they match - any of the four (mesh-file, inline-mesh, periodic inline-mesh, or existing-mesh overloads) - and the remaining N-1 share that first one's mesh, exactly like building spatial_phi1, spatial_phi2, ... from spatial_phi0.get_mesh() by hand.

Template Parameters
TFinite element collection type. Must be given explicitly.
DIMSpatial dimension. Must be given explicitly.
ArgsDeduced argument types, forwarded as-is to the SpatialDiscretization<T, DIM> constructor used to build the first element.
Parameters
NTotal number of SpatialDiscretization objects to build (must be >= 1). The first is built from args..., the remaining N-1 share its mesh.
shared_is_periodicValue passed as is_periodic_mesh to the N-1 mesh-sharing elements. Unused when N == 1.
argsArguments forwarded verbatim to the SpatialDiscretization<T, DIM> constructor used for the first element.
Returns
std::vector<SpatialDiscretization<T, DIM>*> of size N, owned by the caller - release with deleteSpatialDiscretization.
