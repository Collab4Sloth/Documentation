Detailed Description

template<class VARS>
class AdvectionBoundaryCHNLFormIntegrator< VARS >

Inflow/outflow boundary term of the advection operator for the split (phi, mu) Cahn-Hilliard formulation: the advection of phi (block 0) is added to the residual of block 1 (which holds dphi/dt): R_1 = ( (v.n)^+ phi + (v.n)^- phi_in, psi_1 )_Gamma The Velocity and Inflow coefficients are those of phi (block 0), consistently with SplitAdvectionNLFormIntegrator.

Template Parameters
VARSTemplate parameter defining the variables used in the integrator.
