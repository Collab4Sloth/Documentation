Detailed Description

Imposed advection velocity of a block, used by the volume (Advection, SplitAdvection) and boundary (AdvectionBoundary, AdvectionBoundaryCH) integrators.

Two modes, selected from the coefficients of the block:

  • Components: v = (v_x, v_y[, v_z]) given by Glossary::Velocity_X/Y/Z (type Velocity, ID = component). All the components of the space dimension are required.
  • Gradient: v = alpha grad(a), with alpha given by Glossary::VelocityPrefactor and a an auxiliary variable whose symbol is given by the parameter "velocity_gradient" (e.g. Parameter("velocity_gradient", "T")).

In both modes, the coefficients can depend on the coordinates, the time and the auxiliary variables, not on the unknowns (no dv/du in the Jacobian). The auxiliary variable a is frozen in the Jacobian (staggered coupling).

The gradient is evaluated with mfem::GridFunction::GetGradient, which also handles boundary element transformations (gradient taken in the adjacent element).
