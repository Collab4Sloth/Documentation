Detailed Description

Wraps a SLOTH FileCoefficient as an mfem::Coefficient.

Unlike MfemCoefficient, which forwards the values of the variables at the integration point, this wrapper forwards the physical coordinates of the integration point to the wrapped coefficient.

Note
The evaluation time is owned by the wrapped FileCoefficient (set through its set_time()). The mfem::Coefficient time (SetTime / GetTime) is not used.
