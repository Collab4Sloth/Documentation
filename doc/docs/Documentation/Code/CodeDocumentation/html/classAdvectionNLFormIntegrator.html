Detailed Description

template<class VARS>
class AdvectionNLFormIntegrator< VARS >

Volume part of the conservative advection term div(v u_c), integrated by parts.

The velocity v of an advected variable c is imposed through the coefficients of its block (see VelocityField):

  • Glossary::Velocity_X, Velocity_Y (and Velocity_Z in 3D), i.e. type Velocity with ID = index of the component,
  • or v = alpha grad(a): Glossary::VelocityPrefactor (alpha) and the parameter "velocity_gradient" giving the symbol of the auxiliary variable a. Coefficients can be constants or functions of the coordinates ("coordinates"), of the time ("constants": "(t:T)") and of the auxiliary variables, but NOT of the unknowns (the Jacobian contains no dv/du term). In axisymmetric geometry, components are (v_r, v_z).

Each term (r, c) adds to the residual of block r (linear in u_c): R_r = - ( u_c v, grad(psi_r) ) J_rc = - ( v.grad(psi_r), phi_c )

No div(v) is needed: valid for non-solenoidal velocities, int(u_c) is conserved exactly on a closed domain (v.n = 0). On open boundaries (v.n != 0), an Inflow coefficient attached to the boundary activates the inflow/outflow term (AdvectionBoundaryNLFormIntegrator); otherwise the natural condition is a zero advective flux.

Default (Advection): one term (b, b) per block having Velocity coefficients. Derived classes redefine the terms through build_terms() (see SplitAdvection) and may redefine the velocity through compute_velocity().
